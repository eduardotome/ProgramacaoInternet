O que é o Protocolo HTTP?

O HTTP (Hypertext Transfer Protocol) é o protocolo utilizado na Web para permitir a comunicação e a transferência de dados entre o navegador do cliente e o servidor onde os sites estão hospedados.

Como o HTTP é usado na Web

A navegação na Web funciona no modelo cliente-servidor. Quando você acessa um site, o seu navegador envia um pedido (requisição) para o servidor, e o servidor responde enviando de volta o conteúdo da página.

Detalhes de uma Requisição (Request)

Exemplo de uma requisição HTTP enviada pelo navegador:

GET /produtos/notebook.html HTTP/1.1
Host: www.lojaexemplo.com.br
User-Agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64)
Accept: text/html,application/xhtml+xml
Accept-Language: pt-BR,pt;q=0.9

Descrição dos Campos da Requisição:

  • Método (GET): Indica a ação desejada, que neste caso é buscar e ler um recurso do servidor.
  • Caminho (/produtos/notebook.html): O arquivo ou página específica solicitada dentro do servidor.
  • Versão do Protocolo (HTTP/1.1): A versão das regras do HTTP que o navegador está utilizando.
  • Host (www.lojaexemplo.com.br): O endereço do servidor de destino para onde o pedido está sendo enviado.
  • User-Agent: Informações sobre o navegador, sistema operacional e dispositivo do usuário.
  • Accept: Tipos de formatos de arquivo que o navegador consegue receber e processar.
  • Accept-Language: Idioma preferido do usuário para a exibição do conteúdo.

Detalhes de uma Resposta (Response)

Exemplo de uma resposta devolvida pelo servidor:

HTTP/1.1 200 OK
Date: Tue, 29 Sep 2026 14:30:00 GMT
Server: Apache/2.4.52
Content-Type: text/html; charset=UTF-8
Content-Length: 150

<html>
  <body><h1>Notebook Gamer</h1></body>
</html>

Descrição dos Campos da Resposta:

  • Código de Status (200 OK): Indica que a requisição deu certo e a página foi encontrada sem erros.
  • Date: A data e a hora exatas em que a resposta foi gerada pelo servidor.
  • Server: Nome e versão do programa do servidor web que respondeu o pedido.
  • Content-Type: O tipo do arquivo retornado e sua codificação (neste caso, HTML em UTF-8).
  • Content-Length: O tamanho do conteúdo do corpo da resposta medido em bytes.
  • Corpo (Body): O conteúdo real do arquivo solicitado que será renderizado na tela.

Outro Exemplo: Requisição POST

Utilizada quando o cliente envia dados para o servidor, como em um formulário de login:

POST /login HTTP/1.1
Host: www.lojaexemplo.com.br
Content-Type: application/x-www-form-urlencoded

usuario=eduardo&senha=123456
