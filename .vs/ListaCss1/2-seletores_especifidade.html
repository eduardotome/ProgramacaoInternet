Atividade 2 – Especificidade seletores CSS

Arquivo: 2-seletores_especificidade.html

Explicação da aplicação das regras:

  • Item 1 (Abacaxi): Fica vermelho (red). Aplica a Regra 1 (li), pois é o único seletor de elemento que pega essa tag e ela não tem classes ou IDs aplicados.
  • Item 2 (Melão): Fica cinza (gray). Aplica a Regra 3 (.fruta), pois seletores de classe têm maior especificidade que seletores de tag simples (li).
  • Item 3 (Pera): Fica azul (blue). Aplica a Regra 6 (#lip2), pois o seletor por ID tem especificidade maior do que seletores de classe ou tag.
  • Item 4 (Uva): Fica laranja (orange). Aplica a Regra 7 (#lip3.fruta), pois combina ID + classe, sendo mais específica do que a Regra 6 (que usa apenas ID).
  • Item 5 (Maçã): Fica cinza (gray). Aplica a Regra 3 (.fruta), pois não existe nenhuma regra com o ID #lip4.
  • Item 6 (Carne): Fica preto (black). Aplica a Regra 4 (li+li.churras), pois combina elemento + irmão adjacente + classe, superando a Regra 2 (que tem apenas a classe .churras).
  • Item 7 (Linguiça): Fica preto (black). Aplica a Regra 4 (li+li.churras) pelo mesmo motivo do Item 6 (especificidade maior que a Regra 2).
  • Item 8 (Pão de alho): Fica magenta (magenta). Aplica a Regra 5 (.churras[draggable="true"]), pois combina classe + atributo, superando a Regra 4. (A Regra 8 não é aplicada porque busca o id #lip5, mas o ID deste item é #lip7).
